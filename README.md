# CNPROJECT

## Complex Number Operations - TCP Client-Server Application

A TCP-based client-server application that performs complex number operations with encryption support.

### Features

- **Operations Supported:**
  - Exponential of a complex number (e^z)
  - Logarithm of a complex number (log(z))
  - Power of a complex number (z^n)

- **Security:**
  - Data encryption using Fernet symmetric encryption
  - Secure transmission of complex number operations over TCP

### Requirements

- Python 3.7 or higher
- cryptography library

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Singh-Mahendra-07/CNPROJECT.git
cd CNPROJECT
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

### Usage

#### 1. Start the Server

Open a terminal and run:
```bash
python server.py
```

The server will:
- Start listening on `127.0.0.1:65432`
- Generate an encryption key (`secret.key`) if it doesn't exist
- Wait for client connections

Example output:
```
[SERVER] Starting server on 127.0.0.1:65432
[SERVER] Encryption key loaded from secret.key
[SERVER] Server is listening for connections...
```

#### 2. Run the Client

Open another terminal and run:
```bash
python client.py
```

The client will display a menu with operations:
```
==================================================
Complex Number Operations (TCP Client)
==================================================
1. Exponential (e^z)
2. Logarithm (log(z))
3. Power (z^n)
4. Exit
==================================================
```

### Architecture

- **Server (`server.py`):**
  - Listens for TCP connections
  - Decrypts incoming requests
  - Performs complex number operations
  - Encrypts and sends results back to client

- **Client (`client.py`):**
  - Provides interactive menu interface
  - Encrypts user requests
  - Sends requests to server via TCP
  - Decrypts and displays results

### Security Implementation

The application uses Fernet symmetric encryption (part of the cryptography library):
- A shared secret key is generated by the server
- All data transmitted over the network is encrypted
- Both client and server must have access to the same `secret.key` file
- This ensures data confidentiality during transmission

### Technical Details

- **Protocol:** TCP (Transmission Control Protocol)
- **Port:** 65432 (configurable in source code)
- **Host:** 127.0.0.1 (localhost)
- **Encryption:** Fernet (symmetric encryption)
- **Data Format:** JSON for request/response structure
